# --- Sibling units: the host's own services, one line per unit per action ---
# Boat supervises the units that are NOT VMs: the thin pool a VM's disk lives
# in, the network control plane, the wake trap, the fail-closed management
# firewall. internal/units holds the same four names as a closed literal list
# and refuses anything else before a command is rendered; this is the second
# line, and it is what holds if the first is wrong.
#
# EVERY NAME IS FULLY LITERAL. There is no `*` anywhere in this block, and that
# is not fussiness — `systemctl restart *.service` is root, and so is
# `systemctl start atlas-pool.service <anything>.service`, because a `*` in a
# sudoers ARGUMENT matches spaces and sudo joins the user's arguments into one
# string before matching. The per-VM instances are excluded by construction: a
# UUID cannot be spelled with these four literals.
#
# There is no `stop` and no `reset-failed`, and both absences are deliberate.
# A stop is the one verb here with teeth and no driver behind it: stopping
# atlas-wake-trap.service strands every sleeping VM on the host with nothing
# left watching its counter, and nothing in the reconciler would ever notice,
# because the reconciler reconciles VMs and not units. `reset-failed` would let
# the daemon clear a unit's own StartLimitBurst, and a rate limit the
# rate-limited thing can reset is not one. An operator who genuinely needs
# either has SSH break-glass (spec/33-boat.md §12).
#
# The liveness READ needs no grant at all. `systemctl show --property=...` is a
# property read over the system bus that the unprivileged service user can
# make — checked as `sudo -u boat systemctl show ...` on a real host, not
# assumed — so the endpoint Atlas polls for every host in the fleet reaches
# nothing that needs root.
Cmnd_Alias BOAT_SIBLING_UNITS = \
    /usr/bin/systemctl start atlas-pool.service, \
    /usr/bin/systemctl restart atlas-pool.service, \
    /usr/bin/systemctl start atlas-networkd.service, \
    /usr/bin/systemctl restart atlas-networkd.service, \
    /usr/bin/systemctl start atlas-wake-trap.service, \
    /usr/bin/systemctl restart atlas-wake-trap.service, \
    /usr/bin/systemctl start atlas-mgmt-firewall.service, \
    /usr/bin/systemctl restart atlas-mgmt-firewall.service
